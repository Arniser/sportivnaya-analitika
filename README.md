<h2>1. Что такое спортивная аналитика: определение и эволюция</h2>

<p><strong>Спортивная аналитика</strong> представляет собой процесс сбора и интерпретации данных. Целью является получение конкурентного преимущества. Характеристика современного подхода включает использование сенсоров, камер высокого разрешения и алгоритмов искусственного интеллекта.</p>

<p>Ограничения ранних методов заключались в малом объеме выборки. Сегодня обработка происходит в реальном времени. Примером служит система отслеживания траектории мяча в теннисе или футболе, которая генерирует тысячи точек данных за один матч.</p>

<h2>2. Какие метрики заменили традиционную статистику в 2026 году?</h2>

<p>Классические показатели (голы, передачи, фолы) уступили место продвинутым метрикам. Они оценивают качество действий, а не только их результат.</p>

<ul>
	<li><strong>xG (Expected Goals):</strong> Ожидаемые голы. Вероятность того, что удар завершится взятием ворот, исходя из позиции, типа удара и давления защиты.</li>
	<li><strong>xA (Expected Assists):</strong> Ожидаемые результативные передачи. Качество паса, приведшего к удару.</li>
	<li><strong>PPDA (Passes Per Defensive Action):</strong> Интенсивность прессинга. Количество передач соперника между отборами мяча.</li>
	<li><strong>Pack Passing:</strong> Способность игрока проходить сквозь линии обороны одним пасом.</li>
	<li><strong>Shot Quality:</strong> Комплексный индекс качества удара, учитывающий угол, расстояние и положение вратаря.</li>
</ul>
